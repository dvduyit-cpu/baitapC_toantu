Bài tập Toán tử trong lập trình C

Bộ bài tập giúp người mới học luyện các toán tử: +, -, *, /, %, ++, --, ==, !=, >, <, >=, <=, &&, ||, !, +=, -=, *=, /=, ?:

Mỗi bài có 3 chức năng: Hiện gợi ý, Xem đáp án, Đánh dấu hoàn thành.

Đáp án được ẩn mặc định để người học tự làm trước.

Tiến độ học tập: 0/12

PHẦN 1 - TOÁN TỬ SỐ HỌC

CƠ BẢN

Bài 1. Tính toán hai số

Nhập hai số nguyên a và b.

  • Tính tổng
  • Tính hiệu
  • Tính tích
  • Tính thương
  • Tính phần dư
Dùng kiểu dữ liệu int. Sử dụng scanf() để nhập dữ liệu. Khi chia cần kiểm tra b != 0.

Đáp án

#include <stdio.h>

int main() {
    int a, b;

    printf("Nhap a: ");
    scanf("%d", &a);

    printf("Nhap b: ");
    scanf("%d", &b);

    printf("Tong = %d\n", a + b);
    printf("Hieu = %d\n", a - b);
    printf("Tich = %d\n", a * b);

    if (b != 0) {
        printf("Thuong = %.2f\n", (float)a / b);
        printf("Phan du = %d\n", a % b);
    } else {
        printf("Khong the chia cho 0\n");
    }

    return 0;
}

Chú thích

int a, b;: khai báo hai biến số nguyên.

scanf("%d", &a);: nhập số nguyên cho biến a.

a + b: phép cộng.

a - b: phép trừ.

a * b: phép nhân.

a / b: phép chia.

a % b: lấy phần dư.

(float)a / b: ép kiểu để kết quả phép chia có phần thập phân.

CƠ BẢN

Bài 2. Chu vi và diện tích hình chữ nhật

Nhập chiều dài và chiều rộng rồi tính chu vi, diện tích.

Dùng float để cho phép nhập số có phần thập phân. 
#include <stdio.h>

int main() {
    float d, r;

    printf("Nhap chieu dai: ");
    scanf("%f", &d);

    printf("Nhap chieu rong: ");
    scanf("%f", &r);

    float chuVi = (d + r) * 2;
    float dienTich = d * r;

    printf("Chu vi = %.2f\n", chuVi);
    printf("Dien tich = %.2f\n", dienTich);

    return 0;
}

Chú thích

float: lưu số thực.

(d + r) * 2: công thức tính chu vi.

d * r: công thức tính diện tích.

%.2f: hiển thị 2 chữ số sau dấu thập phân.

CƠ BẢN

Bài 3. Tính trung bình cộng

Nhập ba số thực a, b, c và tính trung bình cộng.

Công thức: (a + b + c) / 3 
#include <stdio.h>

int main() {
    float a, b, c;

    printf("Nhap a: ");
    scanf("%f", &a);

    printf("Nhap b: ");
    scanf("%f", &b);

    printf("Nhap c: ");
    scanf("%f", &c);

    float trungBinh = (a + b + c) / 3;

    printf("Trung binh = %.2f\n", trungBinh);

    return 0;
}

Chú thích

Ba biến a, b, c dùng để lưu ba số nhập vào.

Biến trungBinh dùng để lưu kết quả.

Chia cho 3 để tính trung bình cộng.

PHẦN 2 - TOÁN TỬ SO SÁNH

CƠ BẢN

Bài 4. So sánh hai số

Nhập a, b và kiểm tra các phép so sánh.

Kết quả phép so sánh trong C thường là 1 nếu đúng, 0 nếu sai. 
#include <stdio.h>

int main() {
    int a, b;

    scanf("%d", &a);
    scanf("%d", &b);

    printf("a > b = %d\n", a > b);
    printf("a < b = %d\n", a < b);
    printf("a == b = %d\n", a == b);
    printf("a != b = %d\n", a != b);
    printf("a >= b = %d\n", a >= b);
    printf("a <= b = %d\n", a <= b);

    return 0;
}

Ý nghĩa toán tử

>: lớn hơn.

<: nhỏ hơn.

==: bằng nhau.

!=: khác nhau.

>=: lớn hơn hoặc bằng.

<=: nhỏ hơn hoặc bằng.

CƠ BẢN

Bài 5. Kiểm tra chẵn lẻ

Nhập số nguyên n và kiểm tra chẵn hay lẻ.

Kiểm tra n % 2. 
#include <stdio.h>

int main() {
    int n;

    printf("Nhap n: ");
    scanf("%d", &n);

    if (n % 2 == 0) {
        printf("So chan\n");
    } else {
        printf("So le\n");
    }

    return 0;
}

Chú thích

n % 2 == 0: nếu chia 2 dư 0 thì là số chẵn.

else: trường hợp còn lại là số lẻ.

PHẦN 3 - TOÁN TỬ LOGIC

TRUNG BÌNH

Bài 6. Kiểm tra độ tuổi

Kiểm tra tuổi có nằm trong khoảng 18 đến 60.

Dùng toán tử &&. 
#include <stdio.h>

int main() {
    int age;

    printf("Nhap tuoi: ");
    scanf("%d", &age);

    if (age >= 18 && age <= 60) {
        printf("Nam trong khoang\n");
    } else {
        printf("Nam ngoai khoang\n");
    }

    return 0;
}

Chú thích

&& nghĩa là AND - VÀ.

Cả hai điều kiện phải cùng đúng.

TRUNG BÌNH

Bài 7. Kiểm tra ngoài khoảng

Kiểm tra số n nhỏ hơn 0 hoặc lớn hơn 100.

Dùng toán tử ||. 
#include <stdio.h>

int main() {
    int n;

    scanf("%d", &n);

    if (n < 0 || n > 100) {
        printf("Ngoai khoang\n");
    } else {
        printf("Trong khoang\n");
    }

    return 0;
}

Chú thích

|| nghĩa là OR - HOẶC.

Chỉ cần một điều kiện đúng thì toàn bộ điều kiện đúng.

PHẦN 4 - TOÁN TỬ TĂNG GIẢM

TRUNG BÌNH

Bài 8. Toán tử ++

int a = 10;

a++;
++a;
a++;

Hãy dự đoán giá trị cuối cùng của a.

Mỗi lần dùng ++ thì biến tăng thêm 1. 
#include <stdio.h>

int main() {
    int a = 10;

    a++;
    ++a;
    a++;

    printf("a = %d\n", a);

    return 0;
}

Kết quả

a = 13

Từ 10, tăng 3 lần nên thành 13.

NÂNG CAO

Bài 9. Phân biệt a++ và ++a

int a = 5;
int b, c;

b = a++;
c = ++a;
a++: dùng trước, tăng sau.
++a: tăng trước, dùng sau. 
#include <stdio.h>

int main() {
    int a = 5;
    int b, c;

    b = a++;
    c = ++a;

    printf("a = %d\n", a);
    printf("b = %d\n", b);
    printf("c = %d\n", c);

    return 0;
}

Kết quả

a = 7

b = 5

c = 7

Giải thích

b = a++: b nhận 5 trước, sau đó a tăng lên 6.

c = ++a: a tăng từ 6 lên 7 trước, sau đó c nhận 7.

PHẦN 5 - TOÁN TỬ GÁN

TRUNG BÌNH

Bài 10. Toán tử gán kết hợp

int a = 10;

a += 5;
a -= 3;
a *= 2;
a /= 4;
Ví dụ: a += 5 tương đương a = a + 5. 
#include <stdio.h>

int main() {
    int a = 10;

    a += 5;
    printf("%d\n", a);

    a -= 3;
    printf("%d\n", a);

    a *= 2;
    printf("%d\n", a);

    a /= 4;
    printf("%d\n", a);

    return 0;
}

Kết quả từng bước

10 + 5 = 15

15 - 3 = 12

12 × 2 = 24

24 / 4 = 6

PHẦN 6 - TOÁN TỬ BA NGÔI

TRUNG BÌNH

Bài 11. Tìm số lớn hơn

Nhập a và b. Dùng toán tử ba ngôi để tìm số lớn hơn.

Cấu trúc: điều_kiện ? giá_trị_đúng : giá_trị_sai 
#include <stdio.h>

int main() {
    int a, b;
    int max;

    scanf("%d", &a);
    scanf("%d", &b);

    max = (a > b) ? a : b;

    printf("So lon hon = %d\n", max);

    return 0;
}

Chú thích

Nếu a > b đúng thì max nhận a.

Nếu điều kiện sai thì max nhận b.

PHẦN 7 - BÀI TẬP TỔNG HỢP

TỔNG HỢP

Bài 12. Xử lý hai số

  • Tính tổng, hiệu, tích
  • Tính thương, phần dư
  • So sánh hai số
  • Kiểm tra chẵn lẻ
Chia bài toán thành các bước: nhập dữ liệu → tính toán → so sánh → kiểm tra chẵn lẻ → xuất kết quả. 
#include <stdio.h>

int main() {
    int a, b;

    printf("Nhap a: ");
    scanf("%d", &a);

    printf("Nhap b: ");
    scanf("%d", &b);

    printf("\n--- PHEP TINH ---\n");

    printf("Tong = %d\n", a + b);
    printf("Hieu = %d\n", a - b);
    printf("Tich = %d\n", a * b);

    if (b != 0) {
        printf("Thuong = %.2f\n", (float)a / b);
        printf("Phan du = %d\n", a % b);
    } else {
        printf("Khong the chia cho 0\n");
    }

    printf("\n--- SO SANH ---\n");

    if (a > b) {
        printf("a lon hon b\n");
    } else if (a < b) {
        printf("a nho hon b\n");
    } else {
        printf("a bang b\n");
    }

    printf("\n--- CHAN LE ---\n");

    if (a % 2 == 0) {
        printf("a la so chan\n");
    } else {
        printf("a la so le\n");
    }

    if (b % 2 == 0) {
        printf("b la so chan\n");
    } else {
        printf("b la so le\n");
    }

    return 0;
}

Giải thích tổng hợp

Chương trình kết hợp toán tử số học, so sánh, điều kiện và toán tử chia lấy dư.

b != 0 giúp tránh lỗi chia cho 0.

a % 2 == 0 dùng để kiểm tra số chẵn.

if - else if - else dùng để so sánh a và b.
